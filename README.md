## General Information
- Introduction - This project is for building liner regression model for the company Boombikes to study the data set and prepare for the best service post covid.
- Backgroud of the project: The Boombikes suffered a heavy downfall in the usage of bikes lend to the customers
- Problem to be solved - Build a multiple linear regression model for the prediction of demand for shared bikes post covid. The company wants to know: Which variables are significant in predicting the demand for shared bikes and how well those variables describe the bike demands
- Dataset - Bike Sharing data for the pre-covid years

## Conclusions
- As temperature increases, the number of bike rentals increases significantly. This indicates that people prefer using shared bikes in comfortable weather conditions.
- Demand in 2019 is significantly higher than in 2018. This suggests that bike-sharing adoption is increasing over time.
- Poor weather conditions (rain, mist, snow) lead to reduced demand.
- shared bikes are widely used as a mode of daily transport.
- Seasonal planning and resource allocation can help optimize operations.
- shared bikes are widely used as a mode of daily transport.
- Residual analysis confirms that linear regression assumptions are reasonably satisfied.
